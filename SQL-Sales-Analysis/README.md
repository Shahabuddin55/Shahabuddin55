
# 📊 SQL Sales Analysis

## 🛠️ Tools
- SQL
- MySQL

## 📌 Project Overview
This project analyzes the Superstore sales dataset using SQL to identify sales trends, profitable regions, product performance, and customer insights.

## 🔍 Key Analysis
- Calculated total sales, profit, and quantity
- Analyzed sales and profit by region
- Analyzed sales by category
- Identified top 10 products by sales
- Used SQL queries to generate business insights

## 💡 SQL Skills Demonstrated

- Aggregate Functions
- JOIN
- CASE Statements
- LIMIT

## 📊 Key Insights

- Total Sales: $2.30M
- Total Profit: $286.40K
- Total Quantity Sold: 37,873
- Total Orders: 5,009
- Total Customers: 793

### Regional Performance
- West region generated the highest sales: $725.46K
- East region generated the second-highest sales: $678.78K
- West also generated the highest profit: $108.42K

### Category Performance
- Technology generated the highest sales: $836.15K
- Technology also generated the highest profit: $145.45K
- Furniture generated $742.00K in sales but only $18.45K profit

### Top Product
- Canon imageCLASS 2200 Advanced Copier was the highest-selling product with $61.60K in sales.
- It also generated the highest product-level profit: $25.20K

### Business Insight
- Sales and profit increased strongly from 2014 to 2017.
- Furniture has relatively high sales but comparatively low profit, indicating an opportunity to improve margins.
