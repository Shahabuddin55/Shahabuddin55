
# 📊 SQL Sales Analysis

## 🛠️ Tools
- SQL
- MySQL

## 📌 Project Overview
This project analyzes the Superstore sales dataset using SQL to identify sales trends, profitable regions, product performance, and customer insights.

## 🔍 Key Analysis
- Calculated total sales, profit, and quantity
- Analyzed sales and profit by region
- Analyzed sales by category
- Identified top 10 products by sales
- Used SQL queries to generate business insights

## 💡 SQL Skills Demonstrated
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- JOIN
- CASE Statements
- LIMIT

## 📂 Files Included
- `Superstore.csv` – Dataset used for analysis
- `sales_analysis.sql` – SQL queries used in the project
- `Superstore.xlsx` – Excel version of the dataset
- `Superstore-dashboard.png` – Sales dashboard

## 🎯 Project Goal
The goal of this project is to demonstrate practical SQL skills and analyze sales data to support data-driven business decisions.
